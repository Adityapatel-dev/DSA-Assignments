# Data Structures and Algorithms (DSA) Assignments

A collection of **13 C++ programming assignments** covering fundamental Data Structures and Algorithms concepts through practical problem-solving programs.

## 📌 About This Repository

This repository contains C++ implementations of common data structures, graph traversal techniques, and sorting algorithms. Each assignment focuses on a specific problem statement and is intended for MCA coursework, programming practice, and revision.

## 🛠️ Technologies Used

- **Programming Language:** C++
- **Compiler:** GCC / G++
- **C++ Standard:** C++17
- **IDE:** Visual Studio Code
- **Operating System:** Windows

## ⚙️ Setup and Installation

**1. Install a C++ compiler**
```bash
Install GCC/G++ and configure it in your system PATH.
```
**2. Install Visual Studio Code**
```bash
Install VS Code and the C/C++ extension.
```
**3. Clone the repository**

```bash
git clone <YOUR-GITHUB-REPOSITORY-URL>
```

**4. Open the project**
```bash
Open the cloned repository folder in Visual Studio Code.
```
## ▶️ Compile and Run

Open the terminal inside the required assignment folder.

**Compile the program:**

```bash
g++ -std=c++17 -Wall -Wextra source.cpp -o program
```

**Run on Windows PowerShell:**

```powershell
.\program.exe
```

Replace `source.cpp` with the actual C++ filename in the assignment folder.
