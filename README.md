Data Structures and Algorithms (DSA) Assignments
A collection of 13 C++ assignments focused on implementing fundamental Data Structures and Algorithms (DSA) concepts through practical programming problems.
About This Repository
This repository contains C++ programs covering arrays, linked lists, queues, binary search trees, graph traversal, and sorting algorithms. Each assignment is based on a specific problem statement and is organized for learning, practice, and academic reference.
Technologies Used
- Programming Language: C++
- Compiler: GCC / G++
- Standard: C++17 (where supported by the individual program)
- IDE / Editor: Visual Studio Code
- Operating System: Windows

Setup and Requirements
1. Install GCC/G++ on your system.
2. Install Visual Studio Code or another C++ editor.
3. Ensure that the compiler is added to your system PATH.
4. Clone your repository:
git clone <YOUR-GITHUB-REPOSITORY-URL>
5. Open the cloned project folder in Visual Studio Code.
Compile and Run
Open a terminal in the folder containing the assignment's C++ source file.

Compile:
g++ -std=c++17 -Wall -Wextra source.cpp -o program
Run in Windows PowerShell:
.\program.exe
Replace source.cpp with the actual source filename if it is different. If an assignment uses multiple C++ source files, include all required .cpp files in the compile command.
